Labo Blocs

L’atelier où tu fabriques les exercices de programmation de tes projets. Chaque projet (distributeur de céréales…) garde sa copie de son parcours : les élèves travaillent dans le site du projet, et tu lui envoies une nouvelle version avec « Mettre à jour les exercices ».

Que veux-tu faire ?

Créer ou modifier un parcours Exercices, blocs proposés, solution, scénarios de test, indices, carte, compétence évaluée. « Publier » donne le fichier à envoyer au projet. Suivre une classe Ouvre le dossier d’une classe : progression des équipes, niveaux par compétence, note, export CSV et fichier pour le Carnet de classe.

Mise en ligne des parcours

Créer la clé sur GitHub (une seule fois, 3 minutes)
  1. Connecté à ton compte GitHub, ouvre github.com/settings/personal-access-tokens/new (page « New fine-grained personal access token »).
  2. Token name : « Labo Blocs éditeur ». Resource owner : ton compte. Expiration : 1 an (ou la durée la plus longue proposée).
  3. Repository access : Only select repositories › choisis labo-blocs (et rien d’autre).
  4. Permissions : « Add permissions » (ou « Repository permissions ») › Contents › Read and write. Ne touche pas aux autres (« Metadata : Read-only » s’ajoute tout seul).
  5. En bas : Generate token, puis copie la clé (elle commence par github_pat_, GitHub ne la montre qu’une fois) et colle-la ci-dessus.

La clé reste dans ce navigateur, sur cet ordinateur : enregistre-la seulement sur ton ordinateur. Pour l’annuler : même page sur GitHub › la clé › Delete.

Essayer un parcours comme un élève

« Essayer » : tous les exercices sont ouverts et rien n’est enregistré. « Copier le lien élèves » : l’adresse à donner aux élèves (prénoms, classe, dossier de l’équipe).
